01 · Conceito

Halo + valor = Halor.

haloa primeira impressão que ilumina todo o resto + valoro resultado que essa luz gera = haloro halo que vira valor

O nome junta o efeito halo, descrito por Edward Thorndike em 1920, com o valor que ele gera. A primeira impressão ilumina o julgamento de todo o resto, e a Halor existe para capturar essa atenção e mantê-la acesa do primeiro ao último slide: numa aula, num kickoff, numa abertura de evento ou numa reunião de time. O caminho é a experiência. Movimento com propósito guia o olhar, e a interação traz quem assiste para dentro. Por isso o logo é um halo aberto: o vão é a porta por onde a plateia entra.

09 · De Canteiro para Halor

O que muda, tela a tela.

O Canteiro usava a metáfora da obra. A Halor troca a obra pela luz e mantém tudo que já funcionava: editor, acervo, importação, exportação, comentários e administração.

11 · Tokens

Pronto para o front-end.

Copie as variáveis ou use o arquivo design-system/halor-tokens.css do repositório. Os componentes usam só os papéis (--bg, --text, --accent…), então trocar de mundo é trocar uma classe: .theme-night ou .theme-paper.

:root {
  --halor-void:   #07040f;  /* Vazio */
  --halor-violet: #8b3dff;  /* Violeta Halor */
  --halor-neon:   #a970ff;  /* Neon (texto no escuro) */
  --halor-glow:   #c9a6ff;  /* Brilho */
  --halor-lumen:  #f4eeff;  /* Lúmen */
  --paper: #ffffff;  --mist: #f8f6fe;  --lilac-50: #f3eeff;
  --ink:   #17112b;  --ink-2: #4a4366; --line: #e8e3f4;
  --f-display: 'Sora', 'Helvetica Neue', Arial, sans-serif;
  --f-ui:      'Instrument Sans', 'Helvetica Neue', Arial, sans-serif;
  --f-mono:    'JetBrains Mono', ui-monospace, monospace;
  --r-sm: 8px; --r-md: 12px; --r-lg: 18px; --r-pill: 999px;
  --ease-halo: cubic-bezier(.22, .61, .36, 1);
}
.theme-night { --bg: var(--halor-void);  --text: var(--halor-lumen); --accent: var(--halor-violet); }
.theme-paper { --bg: var(--mist);        --text: var(--ink);         --accent: var(--halor-violet); }
